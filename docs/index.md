# Otto

The Ottomatic video engine

## install

Clone the repository

```bash
git clone https://github.com/quaternionmedia/otto.git
cd otto/
```

### Poetry (Recommended)

Install with poetry

```bash
poetry install
```

### Pip

```bash
pip3 install -e .
```

## Rendering

[Rendering](rendering.md) says what otto does with an Edl, and how it writes a
timeline's sound alone. The [reference](reference/render.md) has each function.
